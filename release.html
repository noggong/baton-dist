받아서 설치하기

  1. 내 맥의 칩에 맞는 dmg 를 받습니다 — Apple silicon 은 -arm64, Intel 은 접미사 없는 것.
  2. dmg 를 열어 Baton 을 응용 프로그램 으로 끌어다 놓습니다. 이미 있으면 덮어씁니다.
  3. 앱을 엽니다. 서명·공증본이라 Gatekeeper 경고 없이 열립니다.
  4. 처음 켜면 Setup Gate 가 9스텝 진단을 걷습니다 — 메뉴얼의 시작하기 를 따라갑니다.

자동 업데이트는 없습니다. 새 dmg 로 응용 프로그램 의 Baton 을 덮어쓰면 되고, 데이터(~/.baton)는 재설치해도 그대로 남습니다.

소스에서 빌드하기

dmg 대신 직접 빌드해 쓸 수도 있습니다. 소스 레포는 비공개라 접근 권한이 있어야 합니다 — 받아서 쓰기만 할 거라면 위의 dmg 로 충분합니다. 

git clone git@github.com:noggong/Baton.git && cd Baton
npm install
npm run build
npm start

Jira · gh · Claude Code 없이 전 화면을 만져 보려면 목 모드로 띄웁니다 — BATON_MOCK=1 npm start. 무엇을 눌러도 실제 파일이나 티켓은 건드리지 않습니다.
