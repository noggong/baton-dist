Apple silicon · Intel · 서명·공증본이라 Gatekeeper 경고 없이 열립니다

앱은 판단하지 않고 바통을 넘긴다

Baton 은 원천을 흉내내지 않습니다. worktree 는 git 이 원천이라 git worktree list 를 비추고, 티켓 생성·전이 같은 쓰기는 세션의 에이전트(Atlassian MCP 등)에 넘긴 뒤 결과만 캐시에 반영합니다. 세션은 앱이 Claude Agent SDK 로 직접 듭니다.

보드

워크스페이스 › 프로젝트 › worktree › 세션 › 서브에이전트 5단 트리. worktree 를 그룹으로 묶어 에픽처럼 보고, 트리 행에서 ⌘P 로 그 레포의 열린 PR 을 봅니다.

💬

세션

worktree 마다 세션이 붙습니다. 승인·거부 카드, 코드블록 하이라이팅, ! 셸 모드, 대화 결과물 자동 등록까지 대화 안에서 끝납니다.

⚙️

워크플로우

과업 시작 · 5인 동시 리뷰 → PR → 배포 티켓 · 릴리스 · QA · 일괄 변경 · 추정 · 성과 측정. YAML 파일 하나 더하면 늘어나고, 공개 카탈로그에서 받아올 수도 있습니다 — 코드 변경 없이.

🎫

Jira 클라이언트

내 이슈 목록·상세와 인라인 편집, 댓글 읽음 추적. 읽기는 브라우저 쿠키 세션이라 별도 API 토큰이 필요 없습니다.

🗂️

기록 · 성과

worktree 를 닫으면 요약·대화·링크·산출물이 아카이브되고 FTS5 전역 검색에 들어갑니다. worktree 별 임팩트는 따로 남습니다.

🧑‍🤝‍🧑

역할(에이전트)

지시문 · 모델 · 도구를 정해 둔 역할에 일을 맡깁니다. 세션용 역할은 고르지 않아도 앱이 그 worktree 의 .claude/agents/ 에 깔아 둬, AI 가 필요할 때 바로 부릅니다. 직접 만들어 쓸 수도 있습니다.

화면으로 보기

전 화면과 메뉴별 사용법은 사용자 메뉴얼 에 캡처와 함께 있습니다.

실행 — 워크플로우를 눌러서 돌린다

검색하거나 AI 추천을 받아 고르고, 입력 팝업(최근 선택 기억) → 타임라인 → 채팅 릴레이로 진행을 봅니다.

  • 실패 지점부터 이어서 실행
  • 앱 종료로 끊긴 일 골라서 잇기
  • 크론 예약 · 확인 창에서 더 논의하기
  • 결과를 표 · 키-값 · 마크다운 · JSON 으로

Jira — 티켓을 여기서 본다

브라우저에 로그인해 둔 Jira 의 쿠키 세션으로 내 이슈를 읽습니다. 전이·필드 수정은 그 자리에서, 실패하면 웹으로 폴백합니다.

  • 새 댓글 N 배지로 읽음 추적
  • 브랜치명의 티켓 키로 worktree 와 자동 연결
  • Jira 는 선택 — 미연동이어도 앱은 켜집니다

성과 — 무엇을 냈는지 남는다

worktree 별로 임팩트를 저장합니다. 문서를 연결하거나 AI 에 측정을 위임하고, 활성·보관 모두 검색 색인에 들어갑니다.

  • worktree 닫기 요약과 함께 아카이브
  • ⌘⇧F 통합 검색으로 한 달 뒤에도 찾기
  • 월간 돌아보기 워크플로우로 모아 보기
